## ✨ Key Features

- **Cinematic Apple-Style Scrolling:** Integrated with Lenis.js for buttery-smooth scroll physics and dynamic hero scaling effects.
- **Dynamic Neural Canvas:** A custom HTML5 Canvas background featuring an interactive, physics-based neural network/particle web.
- **Fluid Interactions:** Custom trailing cursor system (dot and ring) with intelligent state management (auto-hides when leaving the window).
- **Dynamic GitHub Integration:** Automatically fetches and displays latest GitHub repositories directly via the GitHub REST API.
- **Glassmorphism UI:** Beautiful translucent panels, blurred backgrounds, and subtle hover elevations for a premium feel.
- **Custom Typography:** Carefully curated local fonts including *Caviar Dreams* for modern sans-serif headings, and *Elegant Typewriter* / *Type Machine* for authentic, vintage coding vibes.
- **Scroll Reveals:** IntersectionObserver-powered reveal animations that gracefully slide and fade content into view as you scroll.
- **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **HTML5:** Clean, semantic structure.
- **CSS3:** Vanilla CSS with custom properties (CSS variables), Flexbox, CSS Grid, keyframe animations, and glassmorphism.
- **JavaScript (ES6+):** Vanilla JS for the canvas rendering engine, API fetching, intersection observers, and custom cursor logic.
- **Lenis:** Lightweight smooth scroll library for fluid movement.
- **GitHub REST API:** Dynamic project fetching.
